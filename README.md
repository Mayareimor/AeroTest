# AeroTest
"AeroTest — plataforma web tipo Test Kit para estudiantes de aviación. Permite practicar exámenes con preguntas aleatorias, generador automático de 50 preguntas, banco de preguntas por materia y tema, dashboard de progreso, panel de administrador y varios modos de estudio. Construida con Next.js, TypeScript, Tailwind CSS y Supabase."
